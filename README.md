# Athlete Performance Visualization

A Python sports-performance analytics project that transforms athlete monitoring data into performance summaries, visualizations, and correlation analysis.

## Objective

The project analyzes multiple athlete-performance variables and creates visual representations of:

- Training load
- Wellness
- Readiness
- Jump performance
- Sprint performance
- Strength

The goal is to demonstrate how Python can be used to transform athlete data into interpretable sports-performance information.
